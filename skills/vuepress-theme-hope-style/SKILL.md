# VuePress Theme Hope 页面美化与样式化规范

## 1. 字符与步骤链路规范
- **箭头符号（严禁 LaTeX）**：
  - 本项目未引入数学公式引擎，严禁使用 `$\rightarrow$` 或 `$\leftarrow$`（会导致未识别代码裸露在页面上）。
  - 必须统一使用原生 Unicode 符号 **`→`** 与 **`←`**。
- **界面操作与步骤链路**：
  - 描述界面点击或操作流转路径时，统一使用行内代码或专名号结合箭头：
  - 推荐范式：``设置` → `应用` → `已安装的应用`` 或 `「设置」→「应用」→「已安装的应用」`。

---

## 2. 原生提示容器（Hint Containers）规范

统一使用主题原生的 `::: 容器类型 [自定义标题]` 语法，不使用 GFM `> [!tip]` 格式。根据信息属性严格选用对应语义容器：

| 容器语法 | 默认标题 | 适用场景 | 示例 |
| :--- | :--- | :--- | :--- |
| `::: tip [标题]` | 提示 | 最佳实践、推荐方案、实用技巧、选型决策 | `::: tip 选型建议` |
| `::: info [标题]` | 相关信息 | 原理剖析、核心机制、概念拆解、格式公式 | `::: info 提炼关键词的黄金公式` |
| `::: note [标题]` | 注 | 辅助背景补充、版本兼容说明、客观备注 | `::: note 版本说明` |
| `::: warning [标题]` | 注意 | 常见陷阱、易错坑点、潜在系统冲突 | `::: warning 谨防捆绑下载` |
| `::: caution [标题]` | 警告 | 高危操作、不可逆修改、数据清空风险 | `::: caution 谨慎操作` |
| `::: details [标题]` | 详情 | 长配置文件、长日志输出、选读参考折叠 | `::: details 查看完整配置` |

### 容器书写格式要求：
1. **标题可自定义**：在容器类型后空格加自定义文字（如 `::: tip 快速排查指南`）；
2. **支持嵌套**：容器内可正常使用列表、粗体、行内代码及标准代码块；
3. **闭合完整**：容器必须以独占一行的 `:::` 结尾。

---

## 3. 视觉重点标记（Mark & Inline Code）
- **高亮文本**：使用 `==重点核心==`（两端需保留空格），渲染为柔和高亮色，适合关键词或结论强调。
- **技术实体**：快捷键（如 `Win + I`）、文件名、路径、终端命令统一使用反引号包裹。

---

## 4. 多平台/多环境切换（Tabs）
当排版包含 Windows / macOS / Linux 差异化步骤时，使用 `::: tabs` 保持版面整洁：
```markdown
::: tabs
@tab Windows
按 `Win + I` 打开设置...
@tab macOS
按 `Cmd + Space` 打开聚焦搜索...
:::
```
