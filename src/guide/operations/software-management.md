# 如何安装和卸载软件：远离流氓捆绑与干净管理

不少新人在使用电脑数月后，经常抱怨系统越来越卡、桌面莫名其妙多出五颜六色的页游图标、右下角动不动跳出弹窗广告。

电脑变慢与弹窗频发的根本原因，在于系统后台被静默安装了大量开机自启、常驻后台的捆绑程序，极大地占用了 CPU 算力与内存带宽。掌握规范的下载、安装与卸载流程，是保持操作系统轻量稳定的基础。

---

## 一、软件获取的“安全级别”

下载软件时，信息来源的安全等级如下：

| 安全级别 | 渠道来源 | 特点与建议 |
| :--- | :--- | :--- |
| 🟢 **S 级（极高）** | **软件官方网站 / GitHub 官方发布页** | 无病毒、无捆绑、版本最新。认准真正的官网域名（警惕搜索引擎顶部的“推广”广告） |
| 🟢 **A 级（高）** | **官方命令行包管理器（winget / Homebrew）** | 开发者标配，一行命令静默安装纯净版（如 `winget install Google.Chrome`） |
| 🟡 **B 级（中等）** | **知名开源镜像站 / 官方软件商店（Microsoft Store）** | 相对受控，但某些商店版功能可能受沙盒限制 |
| 🔴 **D 级（危险）** | **高速下载器 / 第三方下载站（华军、非凡、天空等）** | 充满大号“高速下载”按钮（实为恶意广告下载器），100% 捆绑全家桶与弹窗插件 |

::: warning 谨防“高速下载”陷阱
第三方下载站中体积最大、颜色最醒目的“高速下载”或“安全下载”链接，通常是商业下载器程序。它会在后台静默勾选并捆绑安装推广应用，真实的软件原始安装包通常放置在字号较小的“普通下载”或“本地下载”选项中。
:::

## 二、安装软件时的四项黄金守则

当你双击打开安装包（`.exe` / `.msi` / `.pkg`）时，不要闭着眼睛一路点“下一步（Next）”：

1. **取消所有额外勾选框**：
   留意小字：“同时安装 XX 浏览器”、“设 XX 为主页”、“加入用户体验提升计划”、“开机自启动”，务必全部取消勾选。
2. **选择“自定义安装”（Custom Installation）**：
   不要图省事直接点“一键安装”或“快速安装”。只有进入自定义选项，你才能看清真实的安装路径和隐藏的捆绑选项。
3. **认识安装版与便携版（绿色版/Portable）**：
   - **安装版**：会写入系统注册表、添加开始菜单、关联右键菜单，适合大型日常软件。
   - **便携版/绿色版（Portable）**：解压即可运行，删除文件夹即彻底删除，不污染注册表，非常适合工具类小型软件。
4. **安装路径规划**：
   建议为软件集中规划路径，如 `D:\Softwares\`，避免将大量软件直接扔在根目录或者含有特殊字符的路径下。

## 三、如何干净彻底地卸载软件

很多软件卸载后，依然会在系统内留下数以百计的无用注册表项、后台自启服务以及动辄几 GB 的无用缓存。

### 1. 系统原生卸载入口
- **Windows**：按下 `Win + I` 打开设置 $\rightarrow$ “应用” $\rightarrow$ “已安装的应用” $\rightarrow$ 找到目标软件点击卸载。
- **macOS**：在“访达”（Finder）中将应用程序拖入废纸篓。

### 2. 对付顽固流氓软件：推荐轻量利器
如果遇到系统设置里找不到、或者常规卸载后依然有弹窗残留的流氓软件：
- **推荐工具：Geek Uninstaller（免费、单文件绿色）**
  - 体积仅几 MB，无需安装；
  - 卸载后会自动深度扫描遗留的注册表键值与 AppData 缓存文件夹，并一键强制抹除。
- **排查自启动残留**：
  按下 `Ctrl + Shift + Esc` 打开任务管理器，切换到“启动应用”标签页，将不需要开机自启的非必要软件全部设为“禁用”。

## 四、关于“电脑管家”与“安全卫士”的忠告

很多新手习惯在新买的电脑里安装某某管家、某某卫士来“加速球清理内存”。

在现代 Windows 10/11 系统中：
- Windows 原生自带的 **Windows Defender（安全中心）** 已经是全球顶级的安全防病毒引擎，防护能力极强且静默不打扰；
- 第三方管家软件往往自身就是最大的系统资源占用者与弹窗制造机，甚至会严重干扰开发环境（如误删 Git 进程、拦截本地端口）；
- **结论**：完全无需额外安装第三方杀毒或管家软件，保持良好的软件下载习惯胜过一切防护工具。
