# 基础操作是什么：小白必知的电脑核心操作与习惯

熟练运用操作系统原生的**基础操作与快捷键习惯**，能够缩短文件查找与界面交互的操作链路，显著提升日常处理效率，这也是后续搭建开发环境与使用终端工具的重要基本功。

---

## 一、必须刻进肌肉记忆的快捷键

键盘的效率永远高于鼠标。以下快捷键建议在日常生活中反复练习，直到形成条件反射：

### 1. 通用文本与通用编辑
| 快捷键 (Windows) | 快捷键 (macOS) | 功能说明 | 为什么重要 |
| :--- | :--- | :--- | :--- |
| `Ctrl + C` / `V` | `Cmd + C` / `V` | 复制 / 粘贴 | 最基础文本传递 |
| `Ctrl + X` | `Cmd + X` | 剪切 | 移动文本或文件 |
| `Ctrl + Z` | `Cmd + Z` | **撤销（后悔药）** | 误删或改错瞬间还原 |
| `Ctrl + Y` | `Cmd + Shift + Z` | 重做（反撤销） | 撤销过头时恢复 |
| `Ctrl + A` | `Cmd + A` | 全选 | 快速选中全部内容 |
| `Ctrl + S` | `Cmd + S` | **保存** | 写文章/写代码随时随手按 |
| `Ctrl + F` | `Cmd + F` | 页面/文档内查找 | 瞬间在千行文本中定位关键词 |

### 2. 窗口与多任务切换
| 快捷键 (Windows) | 快捷键 (macOS) | 功能说明 |
| :--- | :--- | :--- |
| `Alt + Tab` | `Cmd + Tab` | **快速切换应用窗口**（单手即可完成应用来回流转） |
| `Win + D` | `Cmd + F3` 或快捷手势 | **瞬间显示桌面** / 再次按下还原 |
| `Win + E` | `Finder` 快捷键 | 快速呼出文件资源管理器（此电脑） |
| `Win + L` | `Ctrl + Cmd + Q` | **锁屏**（离开座位保护隐私的好习惯） |
| `Win + 方向键` | 窗口管理工具 | 屏幕快速半屏分屏（左一半右一半对比资料） |

### 3. 被 90% 新手忽视的宝藏功能
- **Windows 剪贴板历史记录：`Win + V`**
  首次使用需在弹窗中开启。开启后，它会记住你最近复制的数十条文字和图片！再也不用在两个页面之间来回切换复制粘贴了。
- **现代原生高级截图：`Win + Shift + S`（Mac: `Cmd + Shift + 4`）**
  无需安装任何第三方截图软件，框选后自动存入剪贴板，同时支持局部截图、全屏截图与矩形截图。

## 二、文件管理与“路径思维”

新手学习技术最常见的一大障碍是：**找不到文件放在哪**，以及**搞不懂相对路径与绝对路径**。

### 1. 务必开启“文件扩展名显示”
默认情况下，Windows 会隐藏已知文件类型的后缀名（如把 `photo.jpg` 只显示为 `photo`）。这会导致你分不清是普通文本、可执行文件还是脚本。
- **开启方式**：打开此电脑（文件资源管理器） $\rightarrow$ 顶部点击“查看” $\rightarrow$ 勾选“文件扩展名”。
- **好处**：一眼看出是 `.txt`、`.md`、`.exe` 还是 `.zip`，防止被伪装成文本的病毒欺骗。

### 2. 认识“文件路径”
计算机中的每一个文件，都有一个在硬盘上的唯一地理坐标，这就是**路径**：
- **绝对路径（完整地址）**：
  - Windows: `C:\Users\username\Documents\project\index.html`
  - Linux / macOS: `/Users/username/project/index.html`
- **相对路径（以当前所在位置为基准）**：
  - `./`：当前目录
  - `../`：上一级父目录

在后续学习命令行终端和编程时，所有的命令都是在某个具体路径下生效的。培养“知道自己当前身处哪个文件夹”的意识至关重要。

### 3. 避免给文件起糟糕的名字
在技术开发中，养成良好的命名规范能避开无数深坑：
- ❌ **反面教材**：`新建 文档 (2) 最终修改.txt`、`我的 项目 2026.docx`（含中文、特殊符号、大量空格）
- ✅ **推荐范式**：`project-config.json`、`user_profile.py`（使用英文字符、小写字母、下划线 `_` 或短横线 `-` 拼接）。

## 三、系统监控与资源概念

了解你的电脑硬件在如何工作：
- **CPU（处理器）**：电脑的大脑，处理逻辑运算。如果 CPU 飙升到 100%，电脑会变热甚至风扇狂转。
- **内存（RAM）**：工作台。打开的软件越多、浏览器标签页开得越多，占用的内存就越大。内存满了系统就会卡顿或强退后台。
- **硬盘（ROM/SSD）**：仓库。存储所有的文件与操作系统，建议系统盘（通常是 C 盘）至少预留 20%~30% 的空闲空间，否则系统虚拟内存无法运作会导致严重卡顿。

::: tip 观察电脑状态
随时按下 `Ctrl + Shift + Esc` 打开任务管理器，切换到“性能”标签页，就能一目了然看清 CPU、内存、GPU 和磁盘读写的当前负荷。
:::
