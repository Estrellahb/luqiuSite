# 把 Markdown 写作变成稳定流程

Markdown 最好的地方，不是它轻量，而是它能把写作和发布之间的摩擦降到很低。

当文章结构、元信息、图片路径和发布时间都形成固定套路之后，写一篇新内容就不再像“开启一个新项目”，而更像把想法送进已有管道。

## 我喜欢的最小流程

1. 先写标题和摘要句，确定这篇文章解决什么问题。
2. 再补 frontmatter，把日期、分类、标签一次写完。
3. 最后只做必要排版，不在写作阶段频繁打断自己去抠细节。

流程越稳定，表达越不容易被工具本身打断。
