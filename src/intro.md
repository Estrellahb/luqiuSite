# 关于我

陆秋，平时会折腾服务器、个人网站和各种 AI 工具，也在持续学习 AI 应用与 Agent 开发。这个博客主要记录实际做过的项目、部署过程和问题排查，偶尔也会放一些生活与追番内容。

## 希望从事的方向

目前希望寻找与 AI 应用落地、Agent 开发和技术运维相关的工作，比较关注这些方向：

- AI 工作流与 Agent 应用开发
- 大模型接口接入、工具调用和应用部署
- 模型评测、数据整理与 AI 工具测试
- Linux 服务器、Docker、Nginx 和网站部署
- 企业信息化运维与 Windows 桌面支持
- 电商业务中的 AI 工具应用

相比单纯调用一次模型接口，更希望参与能够实际使用、持续维护和逐步完善的项目。

## 做过的项目

### [今天吃什么](/projects/what-to-eat-today)

一款用于安排日常饮食的 Android 应用，包含菜品推荐、菜谱查看、一周计划、购物清单、收藏和烹饪记录。项目使用 uni-app、Vue 3 和 SQLite 开发，已经发布可安装的 Android 版本。

### [通用职业规划 Skill](/projects/universal-career-planning)

面向多种 AI Agent 的职业规划工具，通过访谈、经历盘点、职业方向比较和市场研究，生成职业规划报告与后续行动方案。

更多内容可以在[项目展示](/projects/)中查看。
