# 通用职业规划 Skill

项目地址：[GitHub：Estrellahb/universal-career-planning](https://github.com/Estrellahb/universal-career-planning)

这是一个面向多种 AI Agent 的通用职业规划 Skill，可通过分阶段访谈梳理个人经历、工作价值、能力证据和现实条件，再结合职业方向比较与劳动力市场信息，生成职业规划报告和行动方案。

## 主要功能

1. 开展分阶段职业访谈，整理背景、经历、能力和职业需求。
2. 盘点工作、教育和项目经历，对能力证据进行分级。
3. 生成并比较多个职业方向，分析适配程度、现实障碍和转型成本。
4. 调研目标地区的岗位需求、薪资、资格门槛和发展路径。
5. 生成职业规划报告及 30/60/90 天行动方案。
